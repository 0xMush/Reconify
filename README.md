# Reconify 🚀

---

## ✨ Features

- **Subdomain Enumeration:** Passive and active subdomain discovery using integrated APIs and brute-forcing.
- **Port Scanning & Service Detection:** Fast port scanning to identify open ports and service banners.
- **Directory & File Busting:** Automated discovery of hidden files, endpoints, and directories.
- **Clean Reports:** Automatically aggregates and saves data into structured outputs (TXT).
